Frequently Asked Questions

Common Questions about NativeReplay QA

Why should I use this instead of Selenium or Playwright? +
Selenium and Playwright inject text programmatically into DOM nodes. This often fails to trigger complex client-side listeners, debouncers, or WebGL/canvas controls, and frequently triggers bot-detection barriers on modern applications. NativeReplay QA operates at the OS hardware event layer, ensuring your application behaves exactly as it would with a human user typing at a keyboard.
How does the 2-second delay buffer work? +
When you click "Execute Test" or press F9, a 2-second countdown begins. You simply click into your target web form, desktop app, or text field, and NativeReplay will automatically replay the simulated keystrokes once the buffer expires.
What is the difference between the $29 and $5/mo plans? +
The $29 Standalone plan gives you lifetime access to the desktop runner, allowing you to use your own Google Gemini API key. The $5/month Cloud AI Pro plan includes turnkey cloud AI synthetic test data generation without needing to manage your own API keys or billing accounts.
Can I test non-browser desktop applications? +
Yes. Because NativeReplay emits real OS keyboard events rather than browser-specific DOM code, it functions identically inside VS Code, terminal windows, Slack, desktop ERP software, or any window with an active text cursor.
